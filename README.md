# Atlas-brown Tools

## How do I install these formulae?

`brew install atlas-brown/tools/<formula>`

Or `brew tap atlas-brown/tools` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "atlas-brown/tools"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
